# FlipBook — «Тихие маршруты»

Небольшая демонстрационная электронная книга на четырёх положениях. Проект написан на чистых HTML, CSS и JavaScript: без сборщиков и сторонних JavaScript-библиотек. Книга собрана из физических листов с лицевой и обратной сторонами: каждый лист закреплён внутренним краем у центрального корешка и поворачивается вокруг него.

## Запуск

1. Склонируйте репозиторий или скачайте его файлы.
2. Откройте `index.html` в современном браузере.

Для локального сервера из корня проекта можно выполнить:

```bash
python3 -m http.server 8000
```

Затем откройте [http://localhost:8000](http://localhost:8000).

## Управление

- Нажимайте **«Назад»** и **«Вперёд»**.
- Используйте клавиши ← и →.
- На телефоне листайте книгу свайпом влево или вправо.
- Нажмите **«На весь экран»**, чтобы открыть режим чтения на весь экран; повторное нажатие, кнопка выхода браузера или Escape вернут обычный режим.

## Структура

- `index.html` — разметка приложения;
- `styles.css` — адаптивный разворот, центральный корешок и 3D-листы с двумя сторонами;
- `script.js` — физические листы, навигация, обработка клавиатуры/свайпов и Fullscreen API.
